## 🇨🇳 中文

面向电商商品页，生成或优化商品标题、详情文案和商品页静态图片。技能内按版本规则与参考文件加载，先做信息收集与需求判断，再给出执行计划，最后产出可直接上架使用的内容。既适用于新品上架，也适用于改写优化存量商品页的标题与详情。技能内含 near-miss / should-not-trigger 判断，明确什么请求不该触发它，避免误用。

### ✨ 能做什么

- 输入商品信息 → 输出可直接上架的标题与详情文案
- 优化存量商品页：改写标题与详情表达
- 生成商品页静态图片素材
- 按版本规则加载参考文件，保持口径一致
- 先做信息收集与需求判断，再给执行计划
- near-miss / should-not-trigger 边界判断，减少误触发

## 🇬🇧 English

Generates or optimizes e-commerce product titles, detail-page copy and static product-page images. It follows its version rules and reference-file loading, collects information, judges the actual request, forms a plan, then produces content ready to publish. It fits both new listings and improving the titles and copy of existing product pages. Built-in near-miss and should-not-trigger rules define what it should not handle, reducing misuse.

### ✨ What it does

- Product info in, publish-ready titles and detail copy out
- Rewrites titles and detail copy for existing listing pages
- Produces static product-page image assets
- Loads reference files per version rules to keep wording consistent
- Collects information and judges the request before planning
- Near-miss and should-not-trigger rules cut false activations

- `product-content` — [`product-content/SKILL.md`](product-content/SKILL.md)

